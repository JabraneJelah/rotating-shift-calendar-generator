# Structured content

This directory holds reviewed, typed source content for the Phase 4 pattern guides, route metadata, and approved indexable path inventory. Do not add free-form generated pages or arbitrary route permutations. Content models expose verified identifiers, metadata, assumptions, and substantive sections, and only approved entries may appear in the sitemap.

Exact cycle positions, counts, and dated examples are derived from the public schedule-domain API. Editorial content may import the domain, but the domain must never import content or React. New entries require a distinct user intent, manual factual review, complete internal links, and content-integrity tests before sitemap inclusion.
